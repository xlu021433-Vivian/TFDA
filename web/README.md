# L5 · 神器手机控制

部署入口：**https://l5space.icu/shenqi/**。L5 主页保持不变。

1. 电脑打开0.6.4或更新的神器，登录美团并确认配送地址。
2. 桌面首页点击“连接手机”。连接会记住，随时可以断开。
3. iPhone浏览器打开上面的地址，使用L5管理员账号登录。普通访客或普通注册账号无法控制。
4. 输入需求、预算，点击“用券选1餐”即授权使用电脑当前配送地址选餐。电脑和神器保持运行。
5. 收到真实待支付订单后，在美团官方页面本人付款。登录、验证码、地址及复杂规格可能需要回电脑处理。

## 边界

- 复用宿主已校验的管理员会话、密码变更失效与CSRF；额外验证同源请求。网页、静态资产和API均仅管理员可用并禁止共享缓存。
- 网页不嵌入美团，不导出登录，不创建付款权限。只接受选餐、暂停两类固定请求。
- 本机文件队列位于当前Windows用户的 `%LOCALAPPDATA%/ShenqiDesktop/RemoteBridge`；没有额外网络监听或对公网的本机控制端口。
- 必须新鲜在线、本人本机已启用、无活跃/待核对任务才接收新餐。请求有效60秒，编号执行前持久化；同编号不会重复执行。未知结果需桌面本人核对恢复。
- 暂停撤销尚未接收的餐单，并暂停当前任务及后续定时；不取消已存在的官方订单。
- 只回传连接状态、步骤、简短处理提示与已核对的订单号/金额/官方链接。不回传Cookie、账号、地址、电话或Bark密钥。真实状态和订单传输文件不提交仓库。

## 安装与检查

`deploy/install_l5.py --project <L5项目目录>` 复制独立蓝图与静态资产，从桌面引擎复制公开的需求解析规则；备份两个被改的宿主源码文件。只在已有`is_admin`和CSRF的L5宿主安装，不自动开放其他账号。

```sh
python -m pip install -r web/requirements.txt
python -m unittest discover -s web -p 'test_*.py' -v
```

桌面隔离自检还验证真实WebView2的完整链路：远程队列 → 本机接收 → 点餐引擎 → 模拟加购、用券、单次提交 → 模拟订单回传。模拟不连接真实账号。已完成响应式页面检查；真实账号远程点餐尚待本人首次试运行。

`web/preview.py` 仅在127.0.0.1启动隔离视觉预览，使用dist下测试目录，不连接真实点餐；不要作为公网服务运行。正式部署使用L5蓝图。
