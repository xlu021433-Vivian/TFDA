# 神器 · 网页点餐助手 0.3（电脑 Chrome／Edge）

无需申请美团开发者权限，不需要安卓或模拟器。电脑运行助手，iPhone 用于本人登录验证和付款。

## 安装或更新

1. 解压 `神器-网页点餐助手.zip` 到固定文件夹，里面直接有 `manifest.json`。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择该文件夹。这是浏览器本地扩展设置，不是申请美团应用。
4. 已安装旧版时，替换文件后在扩展管理页点刷新，确认新增的美团站点、本机通知桥接、定时和电脑通知权限。刷新官方网页后重新打开助手。

Codex 内置浏览器不能加载此扩展。请在自己的 Chrome／Edge 登录；不会转移 Codex 浏览器里的账号。

## 自助点餐

1. 打开美团官方 H5 首页，亲自登录、选择地址，进入想点的商家。
2. 点击工具栏扩展图标，打开助手。设置含包装费、配送费的预算，输入“我想喝奶茶，预算30元，一杯”，或留空直接点“帮我随机选”。
3. 从**当前商家已加载菜单**随机挑一个符合要求的在售商品。核对食材；若选“创建待支付订单”模式，还需确认已在官方页面核对当前商家和配送地址，勾选本次单笔自动下单授权，再点“开始自助加购”。不会为了凑券自动多买商品。
4. 复杂规格在官方弹窗中选择，每次加入 1 份后回助手核对。达到目标数量后去结算并尝试用券。
5. 默认免费膨胀：有明确官方“免费膨胀”入口时最多尝试一张，再从本单可用券里选券。膨胀金额和门槛随机、不可撤销；不购买券包、会员或付费升级。确认红包后，再核对商家代金券，避免漏用。
6. **必须读到红包或商家券实际抵扣**，且官方最终合计在预算内，才能创建订单。“已优惠”总数、配送立减、“1张可用”都不算已用券。无券时暂停，不下单。
7. 开始前已勾选本次授权时，助手在预览核对商品、份数、预算和实际用券后，自动单次创建待支付订单，由你付款。若手动来到预览，则核对商家、地址、商品和规格，勾选本单授权后点击创建。设置中可改为只到预览。

手动模式每餐开始前需一次具体授权；定时模式在设置页按时间、预算、选店范围和忌口授权。登录、复杂或未选全的规格、未知状态需要本人处理。保存预算不等于启用定时授权。

## 工作日11点自动点餐、通知付款

打开扩展“定时点餐与付款通知”。默认北京时间周一至周五11:00、券后含包装配送费预算25元、不限定商家，首次安装保持暂停。先在美团官方页面确认账号与配送地址，再勾选授权和启用、保存设置。

到点打开官方首页，从当前配送地址下已加载餐饮商家随机挑选，最多检查5家。只选预算内、符合菜名忌口的餐品；已有购物车不改动，不为凑券增购。可授权使用官方已经选好的默认规格；选项未完整选中、价格不唯一或触发忌口时暂停。最终必须实际用券且券后合计不超过预算才单次提交。

提交后持续观察官方订单详情：必须同时读取真实订单号、待支付状态和与本次提交一致的金额，才通知付款。不会把点击提交当成下单成功，不使用网页查询参数冒充可见订单号。号码或状态无法识别时通知需人工核对，不重试提交。

电脑通知由扩展发出。iPhone Bark通过本机助手转发：在本机面板配置真实Bark key，点“获取扩展通知连接码”，将连接码保存到扩展设置，再发送测试通知。密钥不导出到扩展，连接码只允许调用通知接口，不允许读取账号和配置。缺少有效Bark密钥时不会显示推送已送达。

电脑需开机，浏览器需运行并登录美团，Bark转发还需要本机助手运行。后台定时基于浏览器alarms；休眠不会被唤醒，醒来错过超过10分钟则跳过当天。每天的任务在开始前持久化记录，重启不补下单；上一次提交结果不明时停止下一次。上一工作日订单已明确识别后，可以进入下一日授权任务。GitHub只保存代码，不提供本机网页登录环境。

官方技术依据：[Chrome alarms](https://developer.chrome.com/docs/extensions/reference/api/alarms)、[Bark推送](https://github.com/Finb/Bark/blob/master/docs/tutorial.md)。

## 偏好与自然语言

- 不吃猪肉，排除猪肉制品和未注明来源的可疑肉类名称；随机、手选加购、预览提交三个阶段都检查。
- 必须用券，默认免费膨胀一张，目标为创建待支付订单，由本人付款。
- 常见品类：奶茶、咖啡、果茶、面条、米饭、鸡肉、牛肉、羊肉、轻食。支持 1–10 份，以及“预算30元”“不超过30元”。
- 本地规则解析，不调用云端大模型。无法理解、多品类、额外忌口或糖冰选项时会提示，不假装已满足。
- 奶茶没有匹配时停止，不用蛋糕或面包代替；手动模式不跨店，定时模式可随机选店，未加载商品无法读取。
- 菜名不能保证真实配料；猪油、肉汤等未写入菜名的成分需核对商家说明。

## 提交防重与恢复

提交前先持久化“已尝试提交”标记；所有标签页共用串行防重记录。存储不可用、超预算、未用券、商品无法核对或订单信息变化时停止。只点击“提交订单”，不选择支付控件。

一次点击不等于下单成功，结果以官方订单页为准。网络超时或页面未跳转不自动重试。先到官方订单列表核对，再在助手“已有提交尝试”中勾选核对、解除标记，回商家开始下一餐。旧页面自身的已提交状态不会被解除。

## 权限与数据

请求 `activeTab`、`scripting`、`storage`、`alarms`、`notifications`，站点权限仅限美团H5和本机127.0.0.1:8765。定时授权后可在指定美团站点注入执行；不申请所有网站，不读Cookie、历史记录、验证码或账号存储。

设置、定时任务、防重记录、最近订单号与金额、通知连接码仅保存在扩展本地。手动订单核对指纹仅在页面内存；不保存账号、Cookie或手机号。选配商家链接可能含定位，仅存本机。通知只发送订单号、金额和官方订单链接，不含地址或手机号；Bark由本机配置的服务转发。没有遥测，个人数据不上传GitHub。

淘宝闪购尚未验证，当前不操作淘宝／饿了么页面。
