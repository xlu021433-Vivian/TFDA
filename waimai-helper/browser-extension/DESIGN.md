# 网页点餐工作简报

意图：让只有 iPhone、在 Windows 电脑上工作的本人，使用已登录的美团网页选好一餐，再亲自确认提交和支付。

领域：菜单、食材、规格、购物车、起送价、配送费、预算。配色来自已有助手及餐桌场景：米白餐纸、白瓷、深色字迹、橙红辣椒、浅褐分隔、绿色确认。沿用现有 CSS 色值。

识别点：一张“本次点餐”小票，区分所选小计、官方购物车数量和官方预览合计；未核对结果始终是暂停状态。

结构：页面右上角可收起的本地面板，不另造平台商家搜索页，不用仪表盘卡片堆砌；一条状态信息连接当前操作与下一步。

层级：本餐金额 28px/650，标题 20px，菜名与正文 14px，费用说明 12px。预算和加购主按钮先于辅助入口。中文系统字体，8px 间距基准，16–20px 面板留白，原生按钮和表单控件，44px 点击高度。

深度：单层柔和阴影，米白输入背景，白色面板。暗色跟随系统。状态用语基于实际购物车反馈；复杂规格交还官方弹窗，最后的提交和支付交还本人。

## 自助点餐增量（2026-10-16）

Intent：本人说出想吃什么，在当前官方商家中随机挑选；牢记不吃猪肉，必须实际用券，付款交还本人。
Hierarchy：自然语言输入和“帮我随机选”领先；下方小票明确区分菜品小计、实际红包、商家券、最终应付。待支付模式在预览核对后单次启用。
Palette / Depth / Surfaces：复用米白餐纸、白瓷、橙红操作、绿色抵扣和红色暂停，复用现有单层柔和阴影，避免添加第二套面板样式。
Typography：复用中文系统字体，输入14px、小票28px/650、券和偏好12px，帮助文字降为次要层级。
Spacing：8px 基准，16–20px 留白、44px 控件；菜单和设置分组在狭窄屏幕可滚动。
Signature：小票上常驻“不吃猪肉 · 必须用券”，膨胀一次后重新核对券后应付，不把配送折扣误认为红包。
Defaults：不加聊天气泡列表，不加多卡片仪表盘，不把“已优惠”总数充当已用券证明。

## 定时与付款通知（0.3）

Intent：本人在工作日前配置好午餐，11点生成券后25元以内的待支付订单，在iPhone收到订单号后付款。
Hierarchy：选项页先显示北京时间、预算、启停和最近一次结果；商家与核对过的餐品清单、Bark连接置于下面。真实订单号与“仅尝试提交”必须分开。
Palette / Depth / Surfaces：沿用米白餐纸、白色表单、橙红操作、绿成功红暂停，以及既有单层阴影；不新增仪表盘或聊天气泡。
Typography / Spacing：沿用中文系统字体、28px金额、20px标题、14px正文、12px辅助字；8px间距基准，44px点击区域，移动端自然单列。
Signature：一张定时小票写清“工作日11点 / 券后预算 / 仅待支付”，通知必须带官方页面识别到的订单号，不能编造。
