神器外卖助手 0.3.0 · Windows x64 便携测试版

不用安装 Python，不用敲命令，不用申请美团开发者权限。
请先解压整个 ZIP，保留所有文件在同一个文件夹。不要直接在压缩包里运行。

首次使用（一次性）
1. 双击 INSTALL-EXTENSION.bat：打开浏览器扩展管理页和扩展文件夹。
   在 Chrome / Edge 开启“开发者模式”，点击“加载已解压的扩展程序”，
   选择本包中的 browser-extension 文件夹。这是浏览器加载本地扩展的开关，
   无需申请美团权限。扩展尚未上架商店，所以不能像商店扩展一样一键安装。
2. 在同一个 Chrome / Edge 打开 https://h5.waimai.meituan.com/waimai/mindex/home
   亲自登录并核对配送地址；其他浏览器或 Codex 内置浏览器的登录不会迁移。
   点击浏览器的“扩展”图标，将“神器”固定在工具栏。
3. 双击 START.bat 启动本地面板，运行窗口保持打开。
4. 点击浏览器工具栏的“神器”，先手动试点餐。
   在美团页面出现的自然语言输入框中可输入“我想喝奶茶”等需求。
   打开扩展的“定时点餐与付款通知”，核对工作日 11:00、25 元预算。
   地址和授权确认后，再勾选“启用定时点餐”并保存。

你已经选择的规则
- 不吃猪肉，也排除肉源不清的可疑菜名。菜名无法保证全部配料。
- 不限定商家，随机选餐；实际必须用券，可免费膨胀时最多尝试一张。
- 券后含包装、配送费不超过 25 元；只创建待支付订单，由你付款。
- 无券、超预算、登录失效、复杂规格未选全或提交结果不明时停止。

iPhone 通知（可稍后配置）
- 在 iPhone 安装 Bark，取得自己的 key。
- 本地面板“设置 → Bark key”中填写并保存，密钥只留在自己电脑。
- 本地面板点击“获取扩展通知连接码”，粘贴到扩展的通知设置并保存。
- 点击“发送测试通知”，iPhone 收到后才算配置完成。
- 未配 Bark 仍可使用电脑通知；电脑系统需允许浏览器发送通知。
- 不要把 Bark key 或通知连接码发到聊天、截图或 GitHub。

每天使用
电脑保持开机且不休眠，浏览器运行且美团已登录，START.bat 窗口保持打开。
不需要每天重新安装扩展。GitHub 只是下载和更新入口，不会代替电脑运行。
错过 11:00 超过 10 分钟会跳过当天，不会下午补下单。
iPhone 不能单独运行此 Windows 助手，仅用于接收通知和付款。

现在能用到什么程度
这是可安装测试的版本。真实网页已验证菜单、规格、加购、订单预览、免费券膨胀
和红包抵扣。完整“定时选店 → 自动提交 → 识别真实订单号 → Bark”尚未在真实
账号完成全流程验证；第一次请在电脑旁观察，不要直接依赖它无人值守订午餐。
不会自动付款。淘宝闪购暂未验证。

卸载与更新
先在扩展管理页移除“神器”，关闭 START 窗口，再删除文件夹。
删除文件夹会同时删除该文件夹中的本地 Bark 配置、通知连接码和历史记录。
升级请先关闭旧窗口；不要同时运行两份。不要把本地 app/config.yaml 或 app/data
复制给别人。第三方运行库及其许可证位于 runtime 目录。
