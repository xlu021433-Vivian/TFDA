用已登录的美团网页点餐，不用申请美团开发者权限，也不用安卓或模拟器。

下载 0.3 版电脑浏览器扩展

安装或更新

  1. 下载后解压到固定文件夹，里面直接有 manifest.json。
  2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
  3. 开启“开发者模式”→“加载已解压的扩展程序”，选择文件夹。
  4. 旧版用户替换文件后，在扩展管理页点刷新。新增本地存储只保存预算、模式、膨胀开关及提交防重标记。
  5. 固定扩展到工具栏。Codex 内置浏览器不能加载，请使用自己的 Chrome／Edge。

自助点餐

  1. 打开美团网页版，亲自登录、选择地址并进入商家。
  2. 打开神器扩展。输入“我想喝奶茶，预算30元，一杯”，或直接随机选。
  3. 核对食材、当前商家及配送地址，勾选本次单笔自动下单授权后开始自助加购。复杂规格在官方弹窗选择。
  4. 助手去结算、最多免费膨胀一张并选择可用券，核对实际抵扣及券后合计。无券、超预算或无法确认结果时暂停。
  5. 本次已授权则自动单次创建待支付订单，由你付款；手动来到预览时，可核对后另行授权创建。也可设置只到预览。

提交不明时先核对订单

创建订单前持久化防重标记，多标签页共用。一次点击不代表下单成功。若页面未跳转，先检查官方订单列表，再勾选核对、解除防重记录，回商家开始下一餐。

手动点餐支持当前商家；定时模式可随机选择附近已加载餐饮商家；自然语言是本地常见品类、份数和预算解析。菜名不能保证配料安全。新版自动提交尚未在真实账号验证，结果以官方订单状态为准；淘宝闪购尚未验证。每餐需开始前授权，登录、复杂规格和异常状态仍需本人处理。

工作日11点自动点餐

扩展新增“定时点餐与付款通知”设置页，默认工作日11:00、券后含配送费25元、不限定附近餐饮商家。确认官方地址、授权并启用后执行；识别到真实订单号、待支付及对应金额才通知付款。

Bark需先在本地助手配置真实密钥，再生成通知连接码保存到扩展。密钥不导出、不上传GitHub。执行时电脑、浏览器和本机助手需运行，错过窗口超过10分钟跳过当天。
