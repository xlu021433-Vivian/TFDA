第一次使用

  1. 解压扩展，在电脑 Chrome／Edge 的扩展管理页加载解压文件夹。已安装旧版时，替换文件后点扩展管理页的刷新。Codex 内置浏览器不能直接加载此扩展。
  2. 在美团官方网页亲自登录、选择地址并进入商家菜单。
  3. 打开神器扩展，说出品类和预算；随机挑选后核对食材、当前商家与配送地址，勾选本次单笔授权，开始自助加购。
  4. 复杂规格在官方弹窗中确认。助手核对数量、去结算，尝试免费膨胀一张券并选择可用券，再核对实际抵扣及最终合计。
  5. 满足本次授权条件时，助手自动单次创建待支付订单，你在官方页面付款。未提前授权则停在预览；可在设置中改为只到预览。

当前支持范围

手动点餐读取当前商家菜单；定时模式从附近已加载餐饮商家随机选店，最多检查5家。支持常见品类、份数和预算表达，不为凑券自动增购；经授权可确认官方已选中的默认规格，复杂或未选全的规格暂停。菜名筛选不能保证实际配料安全。

淘宝闪购尚未验证。自动提交和真实订单详情识别尚未在真实账号上端到端验证；不会把一次点击显示为下单成功。扩展的定时、订单记录、通知连接码与运行数据仅保存在本机，不上传GitHub。

网页登录与软件授权的区别

  1. 打开官方页，由你本人完成登录。
  2. 软件不会读取网页 Cookie，也不会猜测是否登录成功。
  3. 微信、支付宝尚未配置本软件的开放平台应用；淘宝闪购消费者授权接口尚未接入。

因此这些入口标为“官方网页”，不会显示成本软件“已连接”。

登录信息如何处理

不索取账号密码不提供密码输入框，不读取微信、淘宝、支付宝网页内容或 Cookie。
仅保留必要授权手机号和验证码临时转发到美团官方；凭证仅在当前进程内存保留，最长两小时。
随时清除点击“清除本软件授权”或关闭软件即可清除本软件凭证；浏览器登录需在官方网页单独退出。
