# 神器桌面助手

## 0.6：L5 的用餐便签

参考：用户指定的 https://l5space.icu/，保留 L5 主页的温柔粉色、奶白玻璃表面、莓果色重点和安静留白。

Domain: 午间歇息、用餐便签、餐后预算、领券膨胀、工作日午餐、等你付款。
Color world: 米饭白、樱花粉、莓果酱、淡陶粉、温暖墨色、叶绿色状态点。
Signature: 一张可填写的用餐便签；券后预算和“不吃猪肉 / 必须用券”像便签上的三条日常约定。
Rejecting: 深绿工具栏改为奶白悬浮页眉；等权重盒子改为需求便签主视觉；大插画占位改为细线碗与花瓣印记。
Intent: 用户在工作间隙输入午餐需求，知道选餐进度和下一步何时付款；安静、亲切、明确。
Hierarchy: 需求便签与单一开始选餐按钮领先；预算在便签下沿，连接状态与高级设置退后。
Palette: L5 莓果 #a33f69 主操作、米粉 #fbf3f6 页面、暖墨 #382d37 正文；绿与红仅表达状态。
Depth: 同一套轻玻璃阴影，不混入重描边；圆角卡片与输入凹面区分层级。
Surfaces: 底 #fbf3f6、奶白玻璃 rgba(255,255,255,.72)、输入 #f3e8ee、弱边界 rgba(151,93,122,.15)。
Typography: 本机可用的微软雅黑正文；宋体衬线标题有日常手记感；26/16/14/12/10px 层级，金额使用等宽数字。
Spacing: 4px 基准，左右20px、卡片16px、主按钮48px、所有操作至少44px；独立滚动和固定操作区继续保留。

UI 改版不改变登录与点餐授权、防重、真实用券、预算和付款边界。域名页面与本机执行状态分别显示，不伪造连接成功。

用户要的是午餐，不是扩展安装。入口为单一桌面 EXE，左侧是点餐、定时和通知，右侧始终是本人登录的官方美团网页。

领域：午餐票、券后预算、配送地址、待支付、工作日、默认规格。
颜色世界：米饭白、餐纸暖白、墨黑、食盒棕、确认绿、需处理的橙红。
签名：固定的“11:00 / ¥25 / 不吃猪肉 / 必须用券”午餐票；官方页和助手之间的就绪状态始终可见。
替代默认：文件树→一个程序；安装命令→明确就绪状态；大仪表盘→单餐操作。

Intent: 不使用命令行的个人用户，在一个窗口登录美团、输入需求并选好这一餐。
Hierarchy: 单个“帮我点这一餐”主操作，金额和真实状态突出，定时/通知收在标签页。
Palette: 暖白、墨色、食盒棕主操作、绿色就绪；颜色只表达操作和状态。
Depth: 轻微表面色差，无大阴影；右侧为官方网页，左侧为可信本地控制区。
Surfaces: #f7f5f0 底、#fffdfa 内容、#efeae2 输入，边界 #e4ded4。
Typography: Microsoft YaHei UI 系统中文字，24px 标题、14px 正文、12px 提示，金额 30px。
Spacing: 8px 基准、24px 外边距，按钮至少44px；窄左栏有独立滚动。

不把渲染成功称为已登录；配送地址由本人确认。未读到实际优惠券、金额或真实订单号时不能显示成功。
登录、验证码、定位许可和付款由本人完成；官方站点之外不接收任何有权限的页面消息。

## 0.4.3：单一助手入口

沿用上面的配色、字号与间距，不增加导航或新品牌。左侧是唯一需求输入、进度、授权、定时和通知入口；右侧只显示美团官方网页。旧网页控制面板仅作为引擎内部状态，不出现在视觉或辅助功能树中；重复注入也不能重新显示。官方登录、商家、规格弹窗和订单详情保持可见。已结束失败记录标为“上次任务已暂停”，避免被误解为刚打开新版就再次失败。

## 0.5：清晰的单餐工作台

Intent: 忙于工作的个人用户快速说明午餐需求，知道下一步由谁操作；桌面助手安静、清楚，不用长篇安装或风险文字挡住主操作。
Domain: 需求便签、券后预算、餐品份数、规格选择、优惠券、待支付、工作日午餐。
Color world: 陶瓷暖白、浅鼠尾草绿、深叶绿、米纸、炭墨、成熟番茄的错误色。
Signature: 小型预算收据与四步点餐进度；实际用券与本人付款始终可查。
Defaults: 大标题和巨型金额→紧凑标题与可编辑预算；长状态堆积→当前步骤与折叠历史；双重入口→左侧唯一控制、右侧官方网页。
Hierarchy: 自然语言输入与一个主按钮领先，快捷示例只填输入、不触发下单；执行时主区域切换为进度与需要本人处理的明确步骤。
Palette: #F5F7F3 暖白底、#FFFFFF 表面、#EDF1E9 输入、#21543E 叶绿主操作、#DDE9C8 轻提示、#203028 正文、#647168 次级文字、#AC4938 错误。
Depth: 表面轻阴影与细边界；无渐变、无装饰大卡片；使用原生输入、按钮、details和tabs。
Typography: Microsoft YaHei UI / Segoe UI，24px标题、14px正文、12px辅助，金额24px；辅助文本至少可读，不用低对比11px堆说明。
Spacing: 4px基准，20px外边距、16px卡片、12px控件间距；主按钮48px，其他交互44px。左栏约400px并可独立滚动，窄栏仍能阅读与操作。
States: 连接不等于登录；未登录禁开始；无效或冲突预算直接解释。按钮忙碌禁重复，暂停始终可用。历史失败默认折叠，未知提交保留防重，不自动开始新餐。
Recovery: 复杂规格停留在官方弹窗，左侧说明只加一份，用户确认后先核对菜品与购物车数量，再继续；无法核对时保持等待，不重复加购。


## 0.5.1：官方页面舒适排版

Intent: 工作中的个人用户直接看清附近餐厅、菜名和价格，仍能辨认官方内容；保持熟悉的官方交互。
Domain: 附近餐厅、起送价、配送费、商品规格、购物车、优惠券、待支付。
Color world: 米饭白、餐纸暖白、鼠尾草绿、深叶绿、炭墨、番茄提示红。
Signature: 左侧需求与预算小票，右侧官方餐厅与菜品；40px可信工具条明确“美团 · 官方页面”，可取消舒适排版。
Defaults: 复制手机整页→仅适配已识别商家/菜品卡片；重写下单组件→保留官方控件；无法撤回主题→一键恢复原样。
Hierarchy: 商家名18px/650、菜名17px/650先于辅助文字；起送/配送/优惠依旧是官方文本。交易页不重新排版。
Palette: 沿用0.5叶绿与纸白变量，信息保持原有语义，不修改金额、商家名或优惠。
Depth: 细浅边界和极轻阴影；不遮挡官方页面，不重排DOM。
Surfaces: #f5f7f3纸底、白卡片、#edf1e9输入、#203028文字、#e4eae0边界。
Typography: Microsoft YaHei UI / Segoe UI；不改html根字号，避免破坏官方rem布局。
Spacing: 4px基准，商家卡18px/窄窗12px，菜品16px/窄窗10px，边界圆角12–16px；不调整购物车或提交按钮定位。
Scope: 仅官方h5首页和菜单；规格弹窗出现时恢复原样；登录、地址、用券、预览、支付及其他域名保持官方原样。主题不发网络请求、不读用户数据、不触发点击。


## 0.5.2：由真实画面修正缩放

Intent: 同一位桌面用户看清菜品、商家与购物车，不让店名和背景图占满工作区。
Evidence: 0.5.1真实米村拌饭页面中手机rem布局按右栏约900px宽度放大，卡片内固定字号与巨大官方标题失衡。此前“不改根字号”的选择不足以满足桌面阅读。
Hierarchy: 官方店名恢复约22px、导航与辅助文字恢复约14–16px，菜品卡17px与之协调；仅在首页和菜单的舒适排版生效。
Palette / Depth / Surfaces: 继续沿用0.5.1的纸白、叶绿、细浅边界，不新增装饰。
Typography: 手机375px设计的rem基准50px封顶，极窄视口13.333333vw；不覆写官方内联样式，移除主题标记后即恢复。
Spacing: 原有官方rem间距随基准回归手机设计尺度；原有卡片内16px/窄窗10px继续保持。
Scope: 规格弹窗、登录、地址、券、交易页面和主题关闭时不应用缩放；不更改WebView全局缩放或左栏字号。WebView隔离测试直接核对计算字号，不仅检查标记存在。


## 0.5.4：白屏时仍可见的恢复入口

Intent: 同一位用户能区分内容加载和屏幕显示；遇到整个网页区空白时无需寻找网页内按钮。
Hierarchy: 44px原生顶部条独立于两块网页，显示“兼容绘制”和唯一“恢复显示”按钮；主内容仍是原有两栏。
Palette / Surfaces: 沿用纸白底、浅叶绿#edf1e9、深叶绿#21543e、辅助字#647168，白色恢复按钮。
Depth: 单层原生控件和浅边界，无遮挡网页的浮层。
Typography: Microsoft YaHei UI 9pt原生辅助字，网页自身字号保持原有规则。
Spacing: 44px顶部条，14px水平边距，112px按钮；用两行表格布局分配空间，避免Dock覆盖内容。
States: 恢复只切换网页控件可见性并重新布局，不导航、不刷新、不加购；软件绘制仅限本程序；进程异常时停止任务。页面内容已加载不再宣称实际屏幕渲染已被验证。

## 0.6.1：一次连接，直接点餐
手机连接放在桌面首页；一个按钮连接或断开，授权后跨重启保留。手机端在用餐便签之前显示真实连接状态，不用折叠帮助猜测是否可用；主按钮直接写明用券、份数和预算，点击即授权本餐，付款仍由本人完成。手机屏幕压缩装饰标题，将需求、预算和按钮放在首屏附近。

## 0.6.2：页面错误恢复
页面不支持或加载失败时，在错误内容旁显示“返回外卖首页”。该操作只导航，不自动恢复失败任务；有未核对提交时隐藏，避免绕过防重。非餐饮页面明确标为非餐饮，不伪装成网络故障。
