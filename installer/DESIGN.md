# Windows 安装入口

沿用 interface-design 的原生控件与层级规则；此入口服务于不使用命令行的个人点餐用户。
领域：午餐、券后预算、配送地址、待支付、工作日、桌面入口。
颜色：餐纸白、墨色、暖灰、餐盒棕、确认绿；只将棕色用于主要安装按钮。
独有信息：工作日 11:00 / 25 元 / 不吃猪肉 / 必须用券的午餐规则摘要。
避免：开发命令清单、仅展示文件树、自动勾选真实下单授权。

Intent: 用户选择安装位置并点击安装，看到明确成功或错误状态。
Hierarchy: 标题 22pt、摘要 11pt、主要按钮 11pt 加粗；路径与说明次之。
Palette: 暖白背景、深棕主要操作、深墨文字；继承现有助手的暖色方向。
Depth: 原生窗口、原生输入和按钮，以间距和字体层级组织内容。
Surfaces: 单一暖白底色，输入保留 Windows 原生白色，保持熟悉的系统交互。
Typography: Microsoft YaHei UI 10pt 正文；标题加粗，使用原生可访问控件。
Spacing: 8px 基准，32px 窗口内边距，控件高度 32–44px。

安装前告知仍需手动加载扩展、登录并确认地址；不打开授权、不设置开机启动。
安装后显示启动、加载扩展、阅读说明按钮。后台校验和解压期间禁止关闭，
出现错误时保留明确错误说明，不覆盖已有配置或删除已有文件。
