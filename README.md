# 神器 · 独立桌面点餐助手

一个 Windows 窗口：左侧输入想吃什么、查看点餐进度、设置定时和通知；右侧直接打开本人登录的美团官方网页。无需 Python、BAT、浏览器扩展或美团开发者权限。iPhone 用于接收 Bark 和本人付款。

## 0.5.1 桌面版

- 0.5.1 新增右侧可切回原样的“舒适排版”，整理商家与菜品卡片。修复医药馆漏筛、商家列表变化及不支持的业务跳转未停止任务。
- 0.5.0 更新单餐界面：输入快捷示例、固定底部操作、步骤进度、规格恢复和折叠历史；右侧只显示美团官方网页。
- 修复暂停竞态、商家券单独用券、复杂规格继续、重复点击和重开后恢复旧任务；提交防重记录需要先暂停并核对官方订单才能解除。
- 单个 EXE，约 1 MB；内置美团官方网页，显示明确连接、登录提示、当前步骤和本次订单结果。
- 单次点餐与循环定时分开授权；旧订单不能冒充新提交结果。通知页可创建桌面快捷方式。
- 登录状态留在内置浏览器；设置、Bark key、任务和订单使用 Windows 当前用户 DPAPI 加密，不上传 GitHub。

- 本地中文输入：餐品、份数、预算与明确饮品规格；输入后立即显示识别结果。例：“想吃河粉 25元预算 一份”。
- 0.4.2 修复普通加购、多规格入口及促销规格价格识别；右侧已选商家时保留当前店铺。
- 默认排除猪肉、猪肉制品及未注明来源的可疑肉类菜名。菜名不能保证完整配料，需了解商家说明。
- 必须读取实际红包或商家券抵扣；配送立减和“券可用”不能替代实际用券。可免费膨胀时最多尝试一张。
- 浏览器本地定时，默认北京时间工作日11:00，券后含配送费预算25元；需要用户启用授权。
- 可不限定商家，从当前配送地址下已加载餐饮商家中随机挑选，最多检查5家；不为凑券自动增购。
- 仅尝试一次订单提交；识别到官方详情的真实订单号、待支付状态及对应金额后，通过电脑通知及本人Bark配置提醒付款。
- 提交结果未知、无券、超预算、售罄、登录失效或复杂规格不完整时停止，不自动付款或重复下单。

## 使用

**[下载独立桌面版 Shenqi-Desktop.exe](https://github.com/xlu021433-Vivian/TFDA/releases/latest/download/Shenqi-Desktop.exe)**，放在固定位置后双击即可，无需解压或安装扩展。在右侧美团页登录并确认地址，左侧输入需求或留空随机，核对预算并勾选本次授权，点击“帮我点这一餐”。定时和 Bark 分别在对应标签页中设置，首次定时关闭。

外部浏览器的登录不会迁移，需本人在内置网页重新登录。电脑和本程序需保持运行；Windows 10/11 x64 需要系统 WebView2 Runtime。本机已安装时不会增加安装步骤。登录、验证码、定位许可和付款均由本人处理。

这是可运行的测试版，完整真实账号下单流程仍待验证，首次请在旁观察。旧扩展版本保留在 [0.3.2 发布页](https://github.com/xlu021433-Vivian/TFDA/releases/tag/v0.3.2)，独立版不需要它。

桌面版构建和隔离验证见 [desktop/README.md](desktop/README.md)。以下为旧版本从源码运行的方法：

1. 安装 Python 3.12+，执行 `pip install -r waimai-helper/requirements.txt`。
2. 执行 `python waimai-helper/build_browser_extension.py` 生成浏览器扩展压缩包。
3. Chrome/Edge扩展管理页加载 `waimai-helper/browser-extension` 文件夹。Codex内置浏览器不能加载此扩展。
4. 运行 `python waimai-helper/app.py`，或使用 Windows 启动脚本。在本地面板配置Bark；真实配置只存在本机。
5. 在美团官方H5亲自登录、确认配送地址。扩展可手动点餐；打开扩展“定时点餐与付款通知”配置授权后启用定时。
6. 本地面板生成扩展通知连接码，保存到扩展通知设置，发送测试通知。不导出Bark密钥。

执行时电脑需开机、浏览器保持运行并登录，本机助手运行时才能转发Bark。关闭或休眠后错过窗口超过10分钟会跳过当天，不在下午补下单。GitHub仓库保存代码，不会在云端代替已登录的本机浏览器操作外卖账号。

详见 [扩展说明](waimai-helper/browser-extension/README.md)。

## 验证与限制

旧版真实美团网页已验证登录、菜单、规格、加购、订单预览、免费券膨胀及红包抵扣。0.4 已在实际 WebView2 中用隔离模拟页面走通左侧按钮、页面桥接、选店、加购、用券核对、单次提交、待支付订单号识别及加密持久化，确认未启用循环任务；模拟不连接真实美团，不产生真实订单或通知。尚未在新桌面版真实账号完成完整下单验证，不承诺平台所有页面均适配。

仅支持当前美团H5页面结构；淘宝闪购未验证。复杂规格和平台风控需要本人处理，不绕过登录或验证码，不使用私有接口。REA用于公开前端代码的静态分析，源码上游为 [morluto/rea](https://github.com/morluto/rea)。原始分析材料和第三方源码未打包进本仓库。

## 开发验证

```sh
npm ci
npm run test:browser
python -m pip install -r waimai-helper/requirements.txt
cd waimai-helper
python -m unittest discover -s tests -q
```

示例配置为 `waimai-helper/config.example.yaml`。账号、Cookie、Bark密钥、通知连接码、地址、定位信息、订单记录、运行时和日志均不应提交；仓库忽略这些本地数据。
